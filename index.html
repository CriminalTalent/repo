최종정산

—

순이익

—

안내 메시지

—
정의: 최종정산 = 배팅금액 × 배수
사용법: 이름 → 금액 → 배수 → 정산하기

도움말

기본 사용법

  • 캐릭터 이름: 선택사항이며, 입력하면 결과에 표시됩니다
  • 배팅 금액: 게임에 걸 금액을 입력합니다
  • 배수: 게임 결과에 따른 배수를 선택합니다
  • 입력 후 정산하기 버튼을 누르면 결과가 계산됩니다

배수 규칙

설정에서 규칙을 설정할 수 있습니다.

기능 설명

  • 결과 복사: 계산 결과를 클립보드에 복사합니다
  • 저장: 현재 결과를 기록으로 저장합니다
  • 비우기: 저장된 모든 기록을 삭제합니다
  • 설정: 규칙과 고정 대사를 설정할 수 있습니다

팁

  • 금액 입력 후 Enter 키를 누르면 바로 계산됩니다
  • 설정한 규칙과 고정 대사는 자동으로 저장됩니다
  • 히스토리 항목에 마우스를 올리면 강조됩니다

설정

배수에 따른 규칙을 자유롭게 작성하세요
결과 복사 시 앞에 붙을 고정 문구를 입력하세요
