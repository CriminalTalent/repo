# 업다운 정산 계산기 📋

## 코드 설명

### 전체 구조
이 계산기는 단일 HTML 파일로 구성되어 있으며, CSS와 JavaScript가 모두 포함되어 있습니다.
브라우저만 있으면 별도의 설치 없이 바로 사용할 수 있습니다.

### 주요 기능

#### 1. 정산 계산
- **입력**: 캐릭터 이름(선택), 배팅 금액, 배수
- **출력**: 최종정산, 순이익
- **공식**: 
  - 최종정산 = 배팅금액 × 배수
  - 순이익 = 최종정산 - 배팅금액
  - 특수 케이스:
    - 배수 0: 본전 (최종정산 0, 순이익 0)
    - 배수 1: 배팅금액만큼 이익 (최종정산 = 배팅금액)

#### 2. 로컬 저장소 (localStorage)
계산기는 브라우저의 localStorage를 사용하여 다음 데이터를 저장합니다:
- `ud_hist`: 정산 히스토리 (배열)
- `ud_rules`: 게임 규칙 설명 (텍스트)
- `ud_fixed_message`: 결과 복사 시 고정 대사 (텍스트)

**중요**: 브라우저 캐시를 지우면 모든 데이터가 삭제됩니다.

#### 3. 히스토리 관리
- **저장**: 각 정산 결과를 타임스탬프와 함께 저장
- **표시**: 최신 항목이 위로 오도록 역순 정렬
- **데이터 구조**:
  ```javascript
  {
    name: "캐릭터 이름",
    amount: 10000,
    m: 5,
    final: 50000,
    profit: 40000,
    ts: 1234567890123
  }
  ```

#### 4. 결과 복사 기능
- 설정한 고정 대사 + 정산 결과를 조합하여 클립보드에 복사
- 형식: 
  ```
  [고정 대사]
  [캐릭터명] 금액 10,000 × 배수 5 = 최종 50,000 / 순이익 40,000
  ```

## 자주 묻는 질문 (FAQ)

### Q1. 데이터가 사라졌어요!
**A**: 브라우저 캐시를 지우면 localStorage 데이터도 삭제됩니다. 
중요한 히스토리는 정기적으로 백업하거나 스크린샷을 저장하세요.

### Q2. 다른 브라우저에서도 사용할 수 있나요?
**A**: HTML 파일이므로 모든 최신 브라우저에서 작동합니다.
단, localStorage는 브라우저별로 독립적이므로 데이터는 공유되지 않습니다.

### Q3. 모바일에서도 되나요?
**A**: 네! 반응형 디자인으로 모바일에서도 잘 작동합니다.
viewport meta 태그와 미디어 쿼리로 최적화되어 있습니다.

### Q4. 설정한 규칙이 어디에 표시되나요?
**A**: 도움말 모달의 "배수 규칙" 섹션에 표시됩니다.
설정에서 입력한 규칙이 자동으로 반영됩니다.

### Q5. 고정 대사는 어떻게 바꾸나요?
**A**: 
1. 우측 상단 톱니바퀴(⚙) 버튼 클릭
2. "고정 대사" 입력란에 원하는 문구 입력
3. "설정 저장" 버튼 클릭

### Q6. 마이너스 배수는 어떻게 계산되나요?
**A**: 
- 배수 -1: 최종정산 = -10,000 (배팅금액만큼 손실)
- 배수 -2: 최종정산 = -20,000 (배팅금액의 2배 손실)
- 순이익은 항상 (최종정산 - 배팅금액)으로 계산됩니다.

### Q7. 히스토리를 백업할 수 있나요?
**A**: 현재는 자동 백업 기능이 없습니다.
브라우저 개발자 도구(F12)를 열어 다음 명령으로 데이터를 복사할 수 있습니다:
```javascript
console.log(localStorage.getItem('ud_hist'));
```

### Q8. 소수점 금액도 입력할 수 있나요?
**A**: 네! 10000.50 같은 형식으로 입력 가능합니다.
결과는 한국 숫자 형식(예: 10,000.5)으로 표시됩니다.

### Q9. Enter 키로 바로 계산할 수 있나요?
**A**: 네! 캐릭터 이름이나 금액 입력란에서 Enter를 누르면
자동으로 정산이 실행됩니다.

### Q10. 여러 사람이 함께 사용할 수 있나요?
**A**: 같은 브라우저를 공유하면 가능하지만, localStorage는 브라우저별로
독립적이므로 각자의 기기에서는 별도로 사용해야 합니다.
